# Crowns of Iron — Art Stage 10.5: Multi-Part Vehicle Assemblies

## Delivered implementation

Extends each of the **120** non-humanoid and vehicle glTF exports (20 vehicle/siege/naval/air archetypes × six factions) from one independently articulated child to **three independently articulated child meshes** per vehicle, alongside its original authored hull.

| Family | Previously attached | New secondary part | New tertiary part |
| --- | --- | --- | --- |
| Air | Spinning propeller | Tail rudder | Wing aileron |
| Naval | Traversing gun turret | Rear rudder | Secondary turret |
| Land/siege | Recoiling artillery barrel | Drive wheel | Armored shield |

Attachments are deterministic low-poly **supplementary mesh geometry**. Original OBJ geometry is neither hand-separated nor individually rigged. Some siege archetypes receive generic machinery accessories as an interim visual treatment.

## Export and browser implementation

- All 120 outputs now contain **four meshes and four nodes** (one body plus three child rigid attachments) with the strict child set `[1,2,3]` on node 0.
- Five pre-existing clips (`idle`, `walk`, `attack`, `hit`, `death`) each contain **five channels**: body translation, body quaternion rotation and one quaternion rotation track for each attachment.
- Browser validation requires the exact hierarchy and node-targeted curves; sampler composes child rotation around its own local pivot, then child anchor and parent motion. UVs and vertex colors accompany all appended parts.
- Attachment behavior is cosmetic only. Server authority, fog visibility, health, collisions, pathfinding and target acquisition remain unchanged.
- Exports are regenerated by the existing `npm run all-216-art-demo` workflow, not checked in as binary glTF files.

## Verification commands

```sh
npm test
npm run syntax-check
npm run all-216-art-demo
npm run protocol-server
```

The 216-model check asserts three separate moving components across all specialized vehicles. The glTF unit tests exercise the four-mesh hierarchy and child animation differences. Open `http://127.0.0.1:5190/model-gallery` to visually inspect.

## Known limitations and safeguards

No final artist-made multi-part rigging, tracks with true wheel geometry, aerodynamic flaps, weapon aim tracking, detachable damage meshes, PBR lighting, hardware FPS certification or graphical golden-image comparisons. Animation is locally procedural and does not change gameplay. This stage is stacked on art stage 10.4 (draft PR #27), and **must not be merged directly into `main` ahead of its dependency**.
